# fastapi-asopetrol-reference

A reference API that demonstrates backend work end to end: a separated domain, tests, containers, infrastructure as code and deployment on AWS.

The domain is original (members, events, registrations): it contains no client code or data.

**Status:** phase 1 in progress — only the vertical health slice (`/healthz`). See [Current state](#current-state).

---

## Stack

| Piece | Choice | Why |
|---|---|---|
| API | FastAPI | Typed validation, dependency injection, generated OpenAPI |
| Validation | Pydantic v2 | Schemas are the contract: if the data does not comply, it does not get in |
| ORM | SQLAlchemy 2.0 (sync) | One mental model; async is a separate decision |
| Database | PostgreSQL | The real engine, not a stand-in |
| Logs | structlog | JSON from day one: filterable and alertable |
| Environment | uv | Reproducible resolution through `uv.lock` |
| Quality | ruff · mypy · pytest | One command for all of it |

## Requirements

- Python 3.12
- [uv](https://docs.astral.sh/uv/)
- Docker (from the database phase onward)

## Running it

```bash
uv sync                                              # installs dependencies and the project
uv run uvicorn app.interface.api.app:app --reload    # http://127.0.0.1:8000
curl http://127.0.0.1:8000/healthz                   # {"status":"ok"}
uv run pytest                                        # tests
```

Interactive documentation generated by FastAPI: `http://127.0.0.1:8000/docs`.

## Structure

```
src/app/
├── domain/            pure rules: no FastAPI, no SQLAlchemy
├── application/       use cases
├── infrastructure/    configuration, observability, persistence
└── interface/api/     routes, HTTP schemas and the app factory
```

The rule is a single one: **dependencies point inward**. The domain imports nothing from the other layers. If that stops holding, the architecture is decorative.

The full design, the decisions and the session plan live in [`DESIGN.md`](DESIGN.md).

## Quality

```bash
make lint     # ruff: lint + format

make test     # pytest
make check    # all three, in order
```

## Decisions

Decisions with real consequences are recorded as ADRs in [`docs/adr/`](docs/adr/):

- **ADR-001 — Synchronous SQLAlchemy.** Sync was chosen for the first slice: the goal of this repository is understanding and judgement, not unmeasured concurrency. Async will be evaluated against a case that justifies it.
